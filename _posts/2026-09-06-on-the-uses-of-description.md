Description is often treated as the preliminary stage of analysis. But description is already a form of interpretation.

What we choose to describe, what we leave aside, and the vocabulary through which we describe something all shape the object that subsequently becomes available for analysis.

## Description as selection

What we choose to describe is never entirely neutral.

A description establishes boundaries. It determines what counts as relevant, what becomes visible, and what remains outside the frame.

This is one reason why description deserves more attention as an intellectual practice.
